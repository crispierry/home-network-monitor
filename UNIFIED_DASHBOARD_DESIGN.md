# Multiple observers

Each observer owns its raw journal. The dashboard can read a dated imported snapshot or an explicitly enabled peer cache. Show host, path, observation time and transfer age separately. Never merge one observer's health into an apparently whole-house assertion.

Compact cache transfer is incremental, bounded and authenticated when enabled. Failure leaves the last verified cache, clearly stale; local collection continues independently. No account password or cloud database is required. The current TLS setup is a restricted two-Mini profile, not automatic general network discovery. See [SYNC_SETUP.md](SYNC_SETUP.md) for setup and limitations.

Agent queries use the same local evidence: `network-monitor query --all-hosts --hours 24`. They do not initiate transfers, probes or load tests. Readable summaries come first; raw evidence remains available on demand at its source.
