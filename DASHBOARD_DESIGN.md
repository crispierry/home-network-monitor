# Dashboard design

Overview prioritizes how often each Mac lost internet access and when it happened. A zoomable internet timeline follows current health, with confirmed interruption counts per observer and explicit unknown recording time. Overlapping confirmed failures to both public HTTPS destinations qualify; isolated destination or other protocol failures remain available in incident details. Counts use retained incidents and are not distinct household-outage totals.

A prominent Show selector switches between either Mini and Both Minis across all sections. The sidebar provides equivalent navigation. Two-observer setups initially show both; a single computer is a complete supported setup. Hide unconfigured peer/satellite lanes and comparison controls; retain failures for configured checks. Cross-observer views explicitly label source and age; a missing peer stays unknown. Incidents always includes the graphical internet timeline; the selected Mini also exposes its detailed path timeline.

Performance starts with the same zoomable internet incident timeline for either Mini or Both Minis, filtered to the selected observers and history range. It separates latency/loss from bandwidth. Time selection, zoom/detail controls and sample inspection support granular investigation. Missing replies and observation gaps remain visible; percentiles describe successful replies and disclose counts. Speed-test intervals are marked because the measurement itself creates load.

Devices use familiar icons plus names/status text. Attachment notes are dated inventory, not live association. Incidents show per-check first failure and recovery; detailed raw context is available on demand. Evidence and Monitoring & storage expose operational details without dominating the overview.

Charts have independent series buttons with generous click targets and shown/hidden accessibility labels. The speed chart supports any combination of observers and download/upload directions. Measured dots, an optional smooth moving-average curve and optional dashed mean lines remain distinct. Numeric averages and test counts follow the visible zoom interval, separately per observer and direction; no combined wired/wireless or download/upload average is shown. The curve uses up to three measured tests and breaks at failures, missing values, interface changes or gaps over two hours. It is a visual trend, not measured throughput between scheduled tests. All-hidden selections show instructions to restore a series.

Use semantic system backgrounds, adaptive light/dark status colors and text labels so color is not the only signal. Supporting text is generally 13 pt or larger; section labels use 12 pt. Disclosure rows have full-width 44-point click targets, with keyboard and accessibility state. Destructive actions require explicit confirmation and leave recording stopped after history deletion. Closing the dashboard does not stop recording.
